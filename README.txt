# ISO 15939 Simulator

A Java-based desktop application designed to simulate the ISO/IEC 15939 software measurement process through an interactive graphical interface.

The application provides a structured environment for defining measurement objectives, planning metrics, collecting data, and evaluating software performance.

## Overview

ISO 15939 Simulator demonstrates software measurement methodologies through a five-stage workflow.

The application combines metric calculations, weighted average analysis, performance scoring, and gap analysis to provide meaningful insights into software measurement processes.

## Measurement Process

The simulator follows five stages:

1. **Profile** — Configure project information and measurement context.
2. **Define** — Establish measurement objectives and select scenarios.
3. **Plan** — Review measurement metrics and evaluation criteria.
4. **Collect** — Enter measurement data and calculate scores.
5. **Analyse** — Evaluate results using weighted averages and gap analysis.

The application uses Java Swing components and a CardLayout-based navigation system to manage the measurement workflow.

Scenario-based metric configurations allow users to explore different measurement contexts.

Automated calculations process collected data and generate performance evaluations.
